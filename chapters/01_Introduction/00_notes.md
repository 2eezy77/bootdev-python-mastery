# Syntax Errors

- Computers version of saying, "I dont understand what you are saying"
- Each computer has it's own language, if you don't use it exactly as it says it can accept it, it will throw a syntax error. 
- While trying to run, syntax errors will halt processing and output a hint to the programmers console.

# What does syntax mean?

- rules for structuring expressions and statements
- can be syntactically correct code, but produce logical errors.

# What happens when you try to run syntax errors?

- Code interpreter will stop and output a syntaxerror with a hint on where the syntax error happened.

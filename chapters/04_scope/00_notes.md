# Scope
* What code is available to be used dependent on where it's in the code.
* From a function's perspective, you can't reuse the predefined parameter names outside of the function or any variables you assign within the function, outside of the function.
* similar to how when you are in the wrong directory you can't open a file that isn't in there, although you might see the file from the file explorer. 

# Global Scope
* global scope describes a variable assigned outside of any function becoming accessible in every other place in in the program file.
* can use pi = 3.14 within any function or outside of any function if it's in the Global scope.
